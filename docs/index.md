# lite-assistant docs

**Get started.** [Install](get-started/install.md) the server and download its models, then [make it speak](get-started/first-program.md).

**Guides.** One task a page, in roughly the order you meet them.

- Talk to it: [speak text](guides/speak-text.md), [transcribe audio](guides/transcribe-audio.md), [chat](guides/chat-with-the-model.md), [speak to the model](guides/speak-to-the-model.md), [talk in real time](guides/talk-in-real-time.md), and [use the chat page](guides/use-the-chat-page.md).
- Shape its replies: [JSON replies](guides/get-json-replies.md), [your own functions](guides/call-your-functions.md), [thinking](guides/let-the-model-think.md), and [your own tools](guides/write-a-tool-file.md).
- Choose and add models: [switch models](guides/switch-models.md), [add models](guides/add-models.md), [find LiteRT models](guides/find-litert-models.md), and [add an engine](guides/add-an-engine.md).
- Photos: [distance](guides/measure-distance.md), [objects and faces](guides/find-objects-and-faces.md), [things by name](guides/find-things-by-name.md), [text](guides/read-text-in-photos.md), [plants](guides/identify-a-plant.md), [editing and ranking](guides/edit-and-rank-photos.md), [lines](guides/follow-a-line.md), and [actions in video](guides/recognize-actions.md).
- Sound: [classify sounds](guides/classify-sounds.md), [tell voices apart](guides/tell-voices-apart.md), [tune an instrument](guides/tune-an-instrument.md), and [remove noise](guides/remove-noise.md).
- Text: [search your documents](guides/search-your-documents.md) and [classify commands](guides/classify-commands.md).
- Run it: [users and keys](guides/manage-users-and-keys.md), [https](guides/serve-over-https.md), [from a board](guides/call-from-a-board.md), and [on Windows from WSL](guides/run-on-windows.md).

**Reference.** [Endpoints](reference/endpoints.md), [engines](reference/engines.md), [built-in tools](reference/built-in-tools.md), [the command line](reference/command-line.md), [where files go](reference/where-files-go.md), and [licences](reference/licences.md).
